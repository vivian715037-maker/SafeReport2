# 지역 선택 목록

`regions.json`은 행정안전부 [주민등록 인구통계](https://jumin.mois.go.kr/statMonth.do)의 지역 선택 목록을 2026-10-24에 확인한 공개 자료입니다. 같은 화면에서 사용하는 `selectHangkikcdListAjax.do` 응답의 시·도(`levels=1`)와 시·군·구(`levels=2`) 코드·명칭만 추렸습니다. 개인별 정보나 인구 통계 수치는 포함하지 않습니다.

확인 시점의 목록은 시·도 16개, 하위 지역 230개입니다. 행정구역은 바뀔 수 있으므로 운영 전에 기준일과 목록을 갱신해야 합니다. 지도 경계·장소 검색은 이 코드 목록과 별도로 OpenStreetMap/Nominatim이 제공하는 결과를 사용하므로 갱신 시점에 차이가 있을 수 있습니다.

현재 클라이언트는 전국 지도를 바로 표시하므로 이 목록을 가져오지 않습니다. 기존 지역 검색 API는 요청한 코드 검증을 위해 목록을 유지합니다. 사용자의 파일 보존 요청에 따라 목록과 호환 API는 삭제하지 않았습니다.
