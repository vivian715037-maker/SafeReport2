# SafeReport — AI 생활안전 신고 지원

사진 → 위치 확인 → AI 분석 또는 수동 입력 → 앱 내부 유사 제보 → 신고문·신고처 → 사용자 상태 기록 → 제보 지도·AI 위험 지도로 이어지는 로컬 MVP입니다. 공식 기관에 자동 신고하지 않습니다.

## 설치와 실행

Node.js **24 이상**, npm, 인터넷 연결이 필요합니다. Windows PowerShell에서:

```powershell
git clone https://github.com/vivian715037-maker/SafeReport2.git
cd SafeReport2
npm.cmd ci
npm.cmd run setup
npm.cmd run dev
```

브라우저에서 [http://127.0.0.1:3000](http://127.0.0.1:3000)을 엽니다. 종료는 터미널에서 Ctrl+C입니다. 이미 설치와 DB 초기화가 되어 있으므로 이 PC에서는 `npm.cmd run dev`만 실행해도 됩니다.

Windows에서 `setup`이나 의존성 재설치 시 `EPERM`이 나오면 실행 중인 개발·운영 서버를 종료한 뒤 다시 실행하세요. Prisma의 DB 엔진 파일이 사용 중일 때 교체가 차단됩니다.

GitHub에는 실제 DB·업로드 사진·백업·환경변수 파일과 검증 화면(`evidence`)을 포함하지 않습니다. 문서에 언급된 검증 증거는 로컬에만 보관됩니다.

Linux 명령은 아래와 같습니다. Linux 환경에서는 이번에 실행 검증하지 않았습니다.

```sh
npm ci
npm run setup
npm run dev
```

최적화 실행은 `npm.cmd run build` 후 `npm.cmd start`입니다. 개발 서버를 종료한 다음 빌드하세요. 같은 프로젝트에서 개발 서버와 빌드를 동시에 실행하지 않는 편이 안전합니다.

## 환경변수와 로컬 저장

- `OPENROUTER_API_KEY`: Windows는 실행기가 현재 프로세스 또는 **사용자 환경변수**에서 읽습니다. 값을 출력하거나 프로젝트 파일에 복사하지 않습니다. 다른 환경에서는 서버 프로세스 환경변수 또는 무시되는 `.env.local`에 설정합니다.
- `OPENROUTER_MODEL`: 기본 `google/gemini-2.5-flash`. 변경 시 이미지 입력·JSON 응답 지원을 확인하세요.
- `DATABASE_URL`: 기본 `file:./fixit.db`이며 Prisma 기준 `prisma/fixit.db`입니다. Prisma CLI용 설정은 `.env`에서 관리합니다. 기본 DB 외 경로를 사용하면 빈 SQLite 파일을 먼저 준비하세요.
- `COOKIE_SECURE=true`: 향후 HTTPS 환경에서만 사용합니다. 현재 HTTP 루프백에서는 지정하지 않습니다.
- `.env.example`만 공유하고 실제 비밀키는 커밋하지 않습니다. DB와 `data/images`도 공유하지 않습니다.

DB에는 제보·상태 이력·해시된 소유권이, `data/images`에는 메타데이터를 제거한 JPEG가 저장됩니다. 재실행해도 유지됩니다. **브라우저 쿠키를 지우면 본인 기록 수정 권한은 복구되지 않습니다.** 사진 API는 소유권·공개 여부를 매번 검사합니다.

## 직접 확인하기

SafeReport는 신고를 접수하는 사이트가 아니라 **신고할 사이트와 신고문을 준비하는 도구**입니다. 새 화면은 다음 4단계입니다.

1. **사진:** 사진 한 장을 고르고 확인합니다. 사진은 우선 비공개 초안으로 저장됩니다.
2. **위치:** GPS 버튼, 장소·주소 검색, 지도 클릭 중 하나로 위치를 선택하고 간단한 장소 설명을 적습니다. 좌표 입력은 지도 장애 시 펼치는 보조 항목입니다.
3. **상황:** 발견한 상황을 한 문장으로 적고 앱 내 유사 제보를 확인합니다. 위험 유형·AI 요약을 따로 입력하지 않습니다. 외부 AI 전송에 동의하면 관찰 분류도 도와줍니다.
4. **신고문:** 추천 공식 사이트 링크를 확인하고 AI로 **제목 / 신고 내용**을 만듭니다. 각각 또는 모두 복사할 수 있으며 공식 사이트에서 직접 제출합니다. AI를 쓰지 못해도 직접 작성할 수 있습니다.

입력 단계만 간결하게 유지하며 일반 사용자를 위한 문구와 세련된 디자인을 사용합니다. 기록 보관과 지도 공개는 선택입니다. 네 번째 화면의 접힌 공개 설정에서 요약 공개 여부를 고르고 사진 공개는 추가 확인합니다. ‘내 기록’에서 이어 쓰기·상태·공개 범위·삭제를 관리합니다. 기존 기록과 소유권 쿠키는 유지합니다.

**위험 지도:** 상단 ‘위험 지도’를 선택하면 전국 지도가 바로 표시됩니다. 전국의 공개 제보를 표시하고 위험도 필터를 제공합니다. 확대·이동으로 원하는 지역을 탐색하고 ‘전국 보기’로 초기 범위에 돌아갈 수 있습니다. 주기적인 데이터 갱신은 사용자의 탐색 위치를 초기화하지 않습니다. 미평가 제보는 판단 불가입니다.

위치 검색은 별도 키 없이 Nominatim을 사용하며 자동완성 없이 검색 버튼으로만 요청합니다. 로컬 단일 서버에서 외부 요청을 초당 1회 이하로 직렬화하고 같은 검색을 하루 동안 캐시합니다. 서비스 장애 시 위치 입력은 GPS·지도 선택으로 이어갈 수 있지만, 장소 검색 조회는 재시도가 필요합니다. 공개 운영 전에는 보장된 지도/검색 제공자를 선정하세요. [Nominatim 이용 정책](https://operations.osmfoundation.org/policies/nominatim/)

이전 지역 선택용 목록과 API는 삭제하지 않고 보존했습니다. 현재 위험 지도는 지역 선택이나 지역 검색 서비스 응답 없이 전국 범위로 바로 열립니다. 위치 입력 단계의 장소·주소 검색은 계속 지원합니다.

### 개선된 중복 확인

GPS 오차를 고려해 **150m 이내 최대 8건**을 제목·설명 유사도, 거리, 유형으로 정렬합니다. AI 전송 동의만 하면 사진 분석 버튼을 먼저 누르지 않아도 비교할 수 있습니다. 후보마다 `같은 위험으로 추정 / 중복 가능성 / 다른 위험으로 추정 / 추가 확인 필요`와 근거를 표시합니다.

AI를 사용하지 못하면 긴 문구 유사도 또는 **공개 동의된 동일 사진**을 보조 근거로 표시합니다. 같은 위치·같은 유형만으로 중복을 확정하지 않습니다. AI에 전송하는 기존 사진은 공개 동의된 사진 중 최대 4장입니다. 비공개 사진은 로컬 동일 사진 검사에도 사용하지 않습니다.

신고 진행 직전에도 AI 사용 선택을 유지합니다. 같은 입력·같은 후보·같은 공개 여부의 성공적인 AI 판단은 5분간 서버 메모리에서 재사용하며, 내용·위치·후보·사진 공개 여부가 달라지면 새로 비교합니다. AI 오류나 응답 누락을 `유사 제보 없음`으로 표시하지 않습니다.

### AI 위험 지도 해석

- 위험도는 사진·설명 관찰에 대한 **AI 추정**이며 현장 확인이 필요합니다. 사고 확률, 기관 검증 결과, 수리 완료를 뜻하지 않습니다.
- 미평가·근거 부족은 회색 `판단 불가`입니다. 초록색 `낮음`도 안전 보증이 아닙니다.
- 근접 핀은 제보 건수를 숫자로, 평가된 제보 중 최대 위험도를 색으로 표시합니다. 제보가 많다고 위험도를 곱하거나 올리지 않습니다. 평가 안 된 제보도 섞여 있을 수 있습니다.
- 제목·설명·유형·요약·위치가 변경되면 이전 위험도는 무효화되어 재분석이 필요합니다. 신고 상태·공개 여부만 바꾸면 평가를 유지합니다.
- 지도 조회 자체는 AI를 호출하지 않습니다. 기존 제보를 자동 분석하지 않으며 다른 사람의 비공개 사진을 평가하거나 공개하지 않습니다.

10분은 **업로드 성공 시각**부터 계산합니다. 만료는 신고 실패나 취소가 아니며 나중에도 완료로 바꿀 수 있습니다. 서버가 꺼져 있어도 다음 조회 시 만료 상태를 보정합니다. 지도·목록은 15초 간격, 작성·상세는 만료 시 재조회합니다. 완료 상태는 만료로 바뀌지 않습니다.

## 검사 명령

```powershell
npm.cmd run test
npm.cmd run test:e2e
npm.cmd run typecheck
npm.cmd run build
npm.cmd audit
```

- 단위 검사: 만료 경계·거리·공개 좌표·신고처·AI 실패 처리.
- Playwright: 설치된 Google Chrome 사용. 별도 `prisma/test.db`, `data/test-images`, 3001 포트, `.next-test`로 실제 API·모바일 흐름·권한·사진 공개·용량·호출 제한을 검사합니다. 유료 AI 요청은 하지 않습니다. **실행할 때 검증 전용 test.db와 테스트 사진을 초기화**합니다.
- `npm.cmd run check:live`: 3000 서버가 켜진 상태에서 합성 사진으로 실제 AI를 **1회 유료 호출**하고 실제 지도 타일·데스크톱 화면을 검사합니다. 테스트 제보는 마지막에 삭제하며 증거는 `evidence`에 저장합니다.
- `node scripts/check-upgrade.mjs`: 합성 위험 2종으로 실제 AI 중복 구분·결과 재사용·새/기존 제보 위험도 저장·위험 지도 표시를 검사합니다. **유료 모델 호출 3회**가 발생하고 생성한 제보만 마지막에 삭제합니다. 기존 제보는 수정하지 않습니다.
- `npm.cmd run check:persistence`: 별도 터미널에서 실행 → READY 후 서버 종료·재시작 → Enter. 소유권·업로드 시각·만료 보존을 확인합니다. 10분을 실제 기다리는 대신 테스트 제보 만료 시각을 과거로 바꿉니다.
- `npm.cmd run demo`: `[데모 데이터]` 제보 1건을 명시적으로 추가합니다. 제거는 `npm.cmd run demo:clear`입니다. 자동 삽입하지 않습니다.

실제 검사 결과와 남은 한계는 [PROJECT.md](PROJECT.md), 처리 흐름과 코드 위치는 [개발설명서.md](개발설명서.md)를 참고하세요.

## 구조와 API

| 위치             | 책임                                 |
| ---------------- | ------------------------------------ |
| `src/app`        | 페이지·스타일·API 진입점             |
| `src/components` | 화면 전환·제보 폼·Leaflet 지도       |
| `src/lib`        | 서버 권한·AI 호출·공유 규칙          |
| `prisma`         | 데이터 모델과 마이그레이션           |
| `scripts`        | 초기화·실행·데모·실제 연결 검증      |
| `tests`          | 단위 검사와 실제 브라우저/API 검사   |
| `evidence`       | 개인 정보 없는 합성 데이터 검증 증거 |

기본 경로는 `/api/reports`입니다. 업로드 `POST /upload`, 본인 목록 `GET /mine`, 공개 지도 `GET /map`, 상세·편집·삭제 `GET/PATCH/DELETE /:id`, 이미지 `GET /:id/image`, AI 분석 `POST /:id/analyze`, 중복 검색 `POST /:id/similar`, 관찰 분석 `POST /:id/inspect`, 신고문 작성 `POST /:id/draft`, 위험도 분석 `POST /:id/risk`, 신고 진행 `POST /:id/publish`, 공개 수정 `PATCH /:id/visibility`, 상태 수정 `PATCH /:id/status`, 신고처 `GET /:id/office`를 제공합니다. 모든 변경은 동일 출처와 소유권을 확인합니다. 상태 API는 `{reported: true/false}`, 공개 API는 `{isPublic,photoPublic,photoConfirmed}`, 분석·관찰·신고문·위험도는 `{consent:true}`, 중복 검색은 `{useAI:true/false}`를 받습니다. 공개 응답에는 `riskLevel`, `riskReason`, `riskAssessedAt`이 추가되며 정밀 좌표·비공개 사진·소유권은 제외합니다.

## 한계와 운영 전 보완 순서

1. **저장·복구:** 현재 SQLite와 로컬 파일은 단일 PC용입니다. 배포 환경이 정해지면 DB·이미지 저장소를 이전하고 같은 시점의 DB와 사진을 함께 백업·복구하는 검사를 합니다.
2. **소유권:** 현재 쿠키만으로 본인 확인합니다. 계정 또는 안전한 복구 수단을 도입하고 다른 계정의 조회·수정 차단을 재검증합니다.
3. **공개 정보:** 자동 얼굴·차량번호 가림, 신고 악용 검수, 보관 기간에 따른 자동 정리, 분실 권한의 삭제 요청 절차는 없습니다. 공개 전 안내만으로 완전한 익명화를 보장하지 않습니다. 운영 전 정책과 실제 삭제·검수 경로를 마련해야 합니다.
4. **운영 제한·비용:** 요청 제한은 브라우저별 서버 메모리라 재시작·쿠키 초기화로 회피할 수 있습니다. 공유 제한 저장소·IP 보조 제한·용량 한도·공급자 예산·오류 지표를 추가하고 부하·비용을 확인해야 합니다. 자동 재시도는 하지 않습니다.
5. **지도·외부 연동:** OSM 공개 타일은 로컬 시연용이며 서비스 보장이 없습니다. 운영 규모·지도 예산은 결정 필요입니다. 지도 제공 서비스·출처 표시·제한을 검토합니다. 자동 주소 검색, 공식 접수 확인은 구현하지 않았습니다.
6. **배포와 보안:** 현재 루프백만 허용합니다. 공개하려면 HTTPS·허용 출처·쿠키·영속 저장·요청 크기 제한·로그의 개인정보 제거를 구성하고 재검증합니다. `npm audit` 0건은 완전한 보안 검증을 의미하지 않습니다.

AI 중복 결과는 **앱 내부 공개 제보만** 대상으로 합니다. 비공개 사진은 다른 제보의 사진 비교에 사용하지 않습니다. 신고처는 규칙 기반으로 안내하고 확인되지 않은 기관명·연락처는 생성하지 않습니다. AI 중복·위험도 판단의 실제 정확도는 다양한 현장 사례로 추가 검증해야 합니다.

장소·지역 검색은 `GET /api/locations?q=검색어`와 `GET /api/locations?region=지역코드`입니다. 기본 검색 서버를 바꾸려면 선택 환경변수 `NOMINATIM_URL`에 호환 검색 엔드포인트를 설정합니다.

`node scripts/check-simple.mjs`는 합성 사진으로 실제 검색·AI 신고문 작성·복사·전국 지도 즉시 표시를 검사합니다. 유료 AI 호출 1회가 발생하며 만든 검증 기록만 마지막에 정리합니다.

## 2026-10-24 신고처 추천 개선

기존 4단계와 전국 위험 지도는 유지합니다. 네 번째 화면과 본인 상세에서 사진 AI 관찰·GPS·장소 설명·위험 유형을 함께 참고해 공식 창구 1~2개와 이유를 표시합니다. 새 AI 호출 없이 저장된 현재 분석을 활용하며, AI 미동의·실패 시에도 수동 설명으로 안내합니다.

- 공식 신고처 DB: `src/data/reporting-channels.json`. 안전신문고, 국민신문고, 한국전력공사 전기상담·고장신고, 112·119를 관리합니다. 기관명·대상·공식 URL·출처·확인일을 버전 관리합니다. 운영 DB를 바꾸거나 기존 제보를 마이그레이션하지 않습니다.
- 출처는 행정안전부, 국민권익위원회, 한국전력공사 공식 안내를 확인했습니다. 불법 주정차 촬영 요건은 연수구청 안내를 참고하되 해당 지역의 시간 기준을 전국 규칙으로 적용하지 않습니다.
- GPS는 국내 서비스 가능 범위를 검사하는 보조 자료입니다. 정확한 행정경계·시설 소유자 DB가 없으므로 특정 시·구청이나 관리사무소를 만들어 추천하지 않습니다. 국내 가능 범위는 관할 판정이 아닙니다.
- 긴급 연락은 일반 추천과 분리합니다. 화재·구조·구급은 119, 진행 중 폭력·범죄는 112를 안내하며, AI 위험도 HIGH만으로 긴급신고를 판정하지 않습니다. 긴급 감지는 제한된 관찰·문구 규칙이므로 탐지되지 않았다고 안전한 것은 아닙니다.
- 사진과 설명의 모순·입력 부족·위치 불확실 시 일반 창구로 안내합니다. 학교 내부와 학교 앞 공공도로, 전력 공급 설비와 건물 내부 설비를 구분합니다. 사유지 주차와 공식 앱 재촬영·지자체별 증빙 조건도 따로 안내합니다.
- 추천의 기관명·연락처·URL은 검증 DB에서만 가져옵니다. AI 응답의 추가 기관·연락처 필드는 거부하고 자유문은 신고처 링크로 채택하지 않습니다. DB는 자동 갱신되지 않으므로 공식 정책·주소 변경 시 사람이 재검증해야 합니다.

검사: Windows에서 단위 테스트 55개, 별도 DB의 실제 API·모바일 흐름 3개, 타입 검사, 최적화 빌드 통과. 합성 사진으로 실제 OpenRouter 호출 1회 후 관찰 결과가 추천에 반영되고 신고문 생성·복사·전국 지도 표시까지 확인했습니다. 이 합성 사진의 위험도는 UNKNOWN이었으며 실제 현장 정확도 점수로 해석하지 않습니다. 테스트는 기관에 신고를 제출하지 않습니다.
